## 一、手稿转录

手写字迹有几处连笔，下面按上下文补齐（存疑处标 ⚠）：

```
速度环一阶 LADRC
输出 y(速度), 输入 u(电流)

ẏ = b0·u + f            (b0 为输入增益; f 为摩擦等并入的扰动)
                        b0 = Kt/J  ⚠ (Kt 可由 KV 估计, b0 允许有误差)

LESO
 ① 扩张扰动            (z1 观测 y)
     ż1 = z2 + b0·u
     ż2 = ḟ = h(t) ≈ 0     (z2 观测 f)
 ② ⚠ 套(龙伯格)观测器   e = (z1 - y)
     ż1 = z2 + b0·u - β1·e
     ż2 = -β2·e
     β1 = 2ω0,  β2 = ω0²   → ω0 受采样频率影响
 ③ 输入 u = (kp·(r - z1) - z2) / b0      (r 指 ref, 目标参考值)

系统框图
        r ──▶(Σ)──▶[ kp ]──▶(Σ)──▶[1/b0]──▶(Σ)──▶ u
              ▲-               ▲-              │
              │                │            (扰动 f)
              z1               z2              │
              └──── LESO ◀─────┴───────────────┘
                        ▲ u, y
```

## 二、与代码逐行对照

| 手稿 | 代码 | 说明 |
|---|---|---|
| `ẏ = b0·u + f` | [LADRC.h:8](../../src/FOC/LADRC.h#L8) | 对象模型：一阶 + 集总扰动 |
| ① `ż1 = z2 + b0·u`，`ż2 ≈ 0` | [LADRC.c:119-120](../../src/FOC/LADRC.c#L119-L120) 的模型项 | 扩张状态：把 `f` 当成新的状态 `z2` |
| ② `e = z1 - y`，`ż1 = z2 + b0u - β1e`，`ż2 = -β2e` | [LADRC.c:117-123](../../src/FOC/LADRC.c#L117-L123) | 代码用 `eo = y - z1`（符号相反），因此是 `+β1·eo`、`+β2·eo`，**与手稿完全等价** |
| `β1 = 2ω0`，`β2 = ω0²` | [LADRC.c:78-79](../../src/FOC/LADRC.c#L78-L79) | 带宽参数化：整定只需 `wc`、`wo` 两个频率 |
| ③ `u = (kp(r - z1) - z2)/b0` | [LADRC.c:110-112](../../src/FOC/LADRC.c#L110-L112) | 反馈用 `z1` 而不是 `y`（观测器输出是无噪状态）；`1/b0` 预先算成 `inv_b0` |
| ⚠ `ω0 受采样频率影响` | `LADRC_SetTs()`，[app.c:134](../../src/app/app.c#L134) | 前向欧拉离散化，`z += ts·ż`。1 kHz 环上主循环会抖，所以**每拍喂实测 `dt`**，不能写死 1 ms |
| `r 指 ref` | `LADRC_Run(l, ref, y)` | 给定与反馈同量纲（本工程都是 RPM） |

## 三、框图对应的工程结构

[`LADRC_typedef`](../../src/FOC/LADRC.h#L39-L57) 里 `z1`/`z2` 就是框图中间两个状态，
`Kp` = `wc`，`beta_1`/`beta_2` 由 `wo` 算出，`inv_b0` = `1/b0`；
`u_max` 是框图最右边的限幅（对应速度环的 iq 上限）。

两个容易踩的实现细节（都写在 [LADRC.c](../../src/FOC/LADRC.c) 头部注释里）：

1. **ESO 的模型项必须用限幅后的 `u`**：否则执行器饱和时观测器会按"不存在的输入"
   推算，`z2` 反而把饱和补偿回去，闭环发散。
2. **控制律用上一拍的 `z1`/`z2`，再更新观测器**：单步内不存在代数环。

## 四、b0 是怎么来的

```
Kt   = 9.5493 / KV              [N·m/A]      (KV 取铭牌值 54 RPM/V)
b0   = Kt / J · (60 / 2π)       [RPM/(s·A)]  (J = 3.0e-5 kg·m²)
     ≈ 0.1768 / 3.0e-5 · 9.5493 ≈ 56290 RPM/(s·A)
```

手稿右下角那句"**Kt 可由 KV 估计，b0 允许有误差**"是这套控制器的关键性质：
`b0` 只决定前馈出多大力，估偏了 ESO 也会把差额并进 `z2` 补回来 —— 所以本机
"KV 已知、转动惯量靠猜"的场合正好适用。工程上用一个系数
`APP_SPEED_ADRC_B0_SCALE` 吸收实测与推算的差异。

## 五、整定顺序（与 README 一致）

1. `APP_SPEED_ADRC_WC_HZ` —— 控制器带宽，决定跟踪快慢；
2. `APP_SPEED_ADRC_WO_RATIO` —— 观测器带宽倍数（默认 4×wc）：跟不上就加，
   iq 高频发毛就减；
3. `APP_SPEED_ADRC_B0_SCALE` —— 最后按实测斜率校。

判读日志（`APP_LOG_ADRC_STATUS`，每秒一行 `[INFO] [ADRC] 速度环: ... z1 ... z2 ... iq`）：

- `iq` 顶在限幅 → 大阶跃起步正常，但**持续**顶住说明 `b0` 偏小或负载偏重；
- `z2` 长时间不为 0 → 恒定的负载/摩擦，属于正常补偿，不是故障。
